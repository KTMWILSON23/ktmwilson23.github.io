Credits & source

XXFHen is a personal host and a customized GoldHEN build for PS4 firmware 14.00. Original authorship remains credited.

The current edition includes a matching XF settings icon and XXFHen names in the Cheat, Patch, and About menu headings. Original credits, support links, settings identifiers, and paths remain intact. Download icon · Artwork prompt and generation method.

Two loading flows

XXFHen: the personal v2.4b18.13 payload, using the raw GoldHEN loading path from Afterglow by well0nez/m0zz. Its original bundled GoldHEN is byte-identical to the file supplied for this personal edition.

Reference HEN: the original loader and bundled HEN from the Sentrix host source. Its CNAME identifies ps4.sentrix.ac. This route retains that source's different v2.4b18.12 wrapper and does not load the personalized XXFHen binary.

The personal build's startup notification reads XXFHen is ready!, followed by Coded by SiSTRo.

Bundled OrbisFTP build 5 — experimental

The regular XXFHen route now loads an installer-free candidate. The OrbisFTP server and libjbc are embedded in xxfhen.bin; the menu prepares /data/XXFHen/oftp.bin and /data/XXFHen/jbc.sprx from those bytes and requests a local background process. It does not install a PKG or launch an installed OrbisFTP title. Its original server startup behavior, including remount attempts, is retained. Port 1337 must be free.

48 modeled backend cases and two native outer-unpack emulator cases pass. Live process creation, library loading and FTP startup still need a console test. The outer data layout expands by 32 KiB; the same XF top-menu logo now uses its 128-pixel mip. Matching bundled-backend patch source, checks and rollback. The previous payload is the installed-app shortcut build the owner reported working.

OrbisFTP diagnostic build 6

The first embedded build loaded on the owner console but stopped at its generic preflight guard before preparing runtime files. This revision identifies individual checks as OF01–OF10 and shows raw system errors where available. 52 backend emulator cases and two native decoder cases pass. This is a diagnostic revision; it does not establish that server startup is fixed. The working installed-app shortcut remains the rollback payload.
